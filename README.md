# Figma Fonts Collection

A curated collection of high-quality fonts commonly used in Figma designs, UI/UX projects, web development, and graphic design.

> **Note:** This repository is intended to make font organization and installation easier for designers and developers. I do **not** claim ownership of any of these fonts.

---

## 📦 What's Included

This repository contains a collection of font files (`.ttf` / `.otf`) organized into font families for easy browsing and use.

Perfect for:

- 🎨 Figma
- 💻 UI/UX Design
- 🌐 Web Development
- 📱 App Design
- 🖥️ Graphic Design

---

## 📂 Repository Structure

```text
fonts/
├── Font Family 1/
├── Font Family 2/
├── Font Family 3/
└── ...
```

---

## 🚀 Getting Started

Clone this repository:

```bash
git clone https://github.com/your-username/figma-fonts.git
```

Install the fonts on your computer using your operating system's standard font installation method.

After installation, restart Figma if it is already running, and the fonts will appear in the font list.
